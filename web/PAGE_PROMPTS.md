Generate a premium redesign of a Login Screen for a web-based chat monitoring dashboard.
**Design Guidelines**: Use DESIGN_VARIANCE 6 (asymmetric layout, maybe a 60/40 split), MOTION_INTENSITY 5, VISUAL_DENSITY 4. Use a dark theme (tinted off-black/navy, no pure black). Use an elegant font like Geist or Outfit.
**Elements to include**:
- A subtle, high-quality background pattern, mesh gradient, or grain effect.
- An elegant logo (maybe a shield or eye icon).
- A heading "Message Monitor" and subheading "Secure access to your message monitoring dashboard".
- A clean password input field (no borders, use subtle elevation/background tint).
- A primary "Unlock Dashboard" button (single accent color, desaturated below 80%).
- An error message state (subtle red text).
- A footer with a lock icon and "End-to-end encrypted session" text.

## Sidebar / Navigation Layout Prompt
Generate a premium redesign of a Sidebar Navigation for a chat application.
**Design Guidelines**: Use DESIGN_VARIANCE 6, MOTION_INTENSITY 5, VISUAL_DENSITY 4. Use an off-black dark theme. Break symmetry, use offset margins for the list items.
**Elements to include**:
- A header area with the app title "Message Monitor" and connection status (e.g., a subtle green dot for connected).
- A search input field (sleek, borderless, icon on the left).
- A filter toggle or tab system ("All" vs "Deleted" messages).
- A list of chat items. Each item needs:
  - An avatar (initials or image with a squircles/rounded square shape, not just a circle).
  - The chat name (SemiBold, sentence case).
  - A timestamp (using tabular figures font).
  - A preview of the last message (truncated, subdued text color).
  - An unread or "deleted" indicator (subtle text label or colored dot, no pill badges).
- A footer or bottom area with a user profile/settings button and a logout button.

## Active Chat View Prompt
Generate a premium redesign of an Active Chat View for a messaging dashboard.
**Design Guidelines**: Use DESIGN_VARIANCE 6, MOTION_INTENSITY 5, VISUAL_DENSITY 4. Use an off-black dark theme. Maximize whitespace and use asymmetric rounded corners for chat bubbles.
**Elements to include**:
- A sticky header showing the active chat's avatar, name, and phone number, with a toggle button "Show Deleted Only" on the right.
- A scrollable message history area containing various message bubbles:
  - Sent messages (right-aligned, subtle accent color background).
  - Received messages (left-aligned, dark grey/tinted background).
  - Messages should show timestamp and text.
  - "Deleted" messages should have a distinct visual state (e.g., a subtle red strike-through, a red border, or an elegant "Deleted" text label).
  - Image messages (thumbnail with rounded corners).
  - Audio messages (minimalist waveform or play button UI).
- An empty state: If no chat is selected, show a composed, beautiful graphic/icon with the text "Select a chat to view messages".
- An image Lightbox overlay: A full-screen dark overlay showing a high-res image with a close 'X' button.

## Settings Panel Prompt
Generate a premium redesign of a Settings Panel for a chat monitoring application.
**Design Guidelines**: Use DESIGN_VARIANCE 6, MOTION_INTENSITY 5, VISUAL_DENSITY 4. Dark theme, high-quality typography (Geist/Outfit). Use a slide-over or dedicated page layout.
**Elements to include**:
- A header with a "Back" button and title "Settings: Manage monitored chats and notification preferences".
- A toggle switch "Forward deletions to WhatsApp" with description "Send yourself a message when someone deletes a message". Use an elegant custom toggle, not default browser UI.
- A search bar "Search chats...".
- Two elegant tab buttons: "Monitored" and "Available".
- A list of chats (similar to sidebar but with actions):
  - Avatar, name, group/private label.
  - A sleek "Add" or "Remove" button next to each item.
- A "Danger Zone" section with a red accent (low saturation):
  - Title "Clear all data" and description "Delete all stored messages, media, and chat history. This cannot be undone."
  - A "Clear Data" button.
  - An inline confirmation state showing a password input and "Yes, delete everything" / "Cancel" buttons.
