Redesign the current chat application using the following premium design guidelines (Taste Skill and Redesign Skill).

## Application Context
We are redesigning a WhatsApp Web-like chat interface with a sidebar (containing a list of chats with search and filters), a main chat view (showing a conversation history with text, images, audio, a message input area, and deleted message indicators), a user settings panel (for preferences and logout), and a login screen.

## Design Settings
- DESIGN_VARIANCE: 6 (Break symmetry with offset margins or varied sizes, some overlapping, clean asymmetric grids).
- MOTION_INTENSITY: 5 (Smooth fade-ins on load, smooth scrolling, subtle scale/translate on hover).
- VISUAL_DENSITY: 4 (Normal app spacing, well-balanced whitespace but appropriate for a web app dashboard).

## Typography
- Use a high-quality modern font with character, such as Geist, Outfit, or Satoshi, instead of default Inter/system fonts.
- Headlines should have presence (tighter letter-spacing, heavier weight). Use Medium (500) and SemiBold (600) for subtle hierarchy in chat names and message meta-data.
- Use tabular figures for timestamps and numbers.
- Avoid all-caps subheaders; prefer lowercase italics or sentence case.

## Color and Surfaces
- Use an off-black/tinted dark background (e.g., #0a0a0a or a dark navy) instead of pure black for dark mode, or a cohesive tinted light background. Commit to a consistent tone.
- Select a single, considered accent color and keep saturation below 80% so it blends with neutrals.
- Remove harsh black shadows. Tint shadows to match the background hue and use negative margins or overlapping for depth instead of generic borders.
- Add subtle noise, grain, or ambient gradients to backgrounds rather than keeping them purely flat. Break uniform gradients with radial or mesh gradients.

## Layout and Spacing
- Ditch the generic 100vh equal-column layout. Use an asymmetric grid or a slightly offset split view for the sidebar and chat view.
- Increase whitespace and let the design breathe. Double the spacing in sidebars and headers compared to a generic dense app.
- Ensure consistent vertical rhythm across side-by-side elements (like timestamps aligning properly with message bubbles or chat list items).
- Provide max-width container constraints so it doesn't just awkwardly stretch edge-to-edge on very wide displays.

## Interactivity and States
- Ensure all interactive elements (buttons, chat items, settings toggles) have hover states (background shift, slight scale/translate) and active/pressed feedback (`scale(0.98)`).
- Provide smooth transitions (200-300ms) for all state changes.
- Design elegant skeleton loaders for loading states instead of basic spinners.
- If there are no chats or no selected chat, design a composed, beautiful "empty state" instead of a blank screen.

## Component Patterns
- Remove generic card borders and pure white backgrounds with harsh shadows. Rely on spacing and subtle elevation for hierarchy.
- Avoid pill-shaped generic badges for things like "deleted message" or "unread"; try subtle text labels, squares, or small elegant indicators.
- Avoid generic icon sets like bare Lucide/Feather. Use a more distinct style (like Phosphor or custom geometric icons). Use consistent stroke weights for all icons.

## Output Requirements
Generate the UI for the following key views:
1. The Login Screen (centered, off-balance or split with a subtle ambient background).
2. The Main Dashboard View (Sidebar with chat list + Active Chat View with message bubbles).
3. The Settings Panel (Overlay, slide-over, or distinct view).
Make sure to apply the premium design aesthetics detailed above to every generated view.
